OFFICE REPOSITORY WEBSITE UPDATE

1. Make a backup of your current index.html.
2. Copy the contents of this folder into your GitHub repository folder.
3. Keep the folder structure exactly as shown:
   index.html
   style.css
   images/hero.jpg
   blog/ai-fundamentals.html
   blog/python-business-analytics.html
   blog/first-website.html

4. Add your own picture:
   - Put a JPG image in the images folder.
   - Name it hero.jpg.
   - If your image has another extension, update src="images/hero.jpg" in index.html.

5. Preview:
   - Open index.html in VS Code.
   - Right-click the file and choose Open with Live Server if you have that extension.
   - Or open index.html in your browser.

6. Publish:
   - Save all files.
   - In GitHub Desktop, commit the changes and click Push origin; OR upload the changed files/folders to the repository on GitHub.
   - Wait a minute or two, then refresh your GitHub Pages website.

The articles are starter drafts. Edit the text in each HTML file in the blog folder.
